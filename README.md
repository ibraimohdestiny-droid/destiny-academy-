# Destiny Academy

> **Learn. Build. Grow.** — a modern, responsive landing page for a practical digital-skills academy.

## Overview

Destiny Academy is a lightweight static website designed to present digital-skills training in a clear, professional and mobile-friendly way.

### Courses

- Microsoft Word
- Microsoft Excel
- PowerPoint
- CorelDRAW
- GitHub
- Web Development
- Programming
- Artificial Intelligence

## Features

- Responsive design for phones, tablets and desktops
- Modern academy-focused visual identity
- Hero section with clear calls to action
- Eight course cards
- About and learning philosophy section
- Contact call-to-action
- Mobile navigation menu
- Semantic HTML and responsive typography
- No build tools or framework required

## Getting started

No package installation is required.

1. Upload the four files to your GitHub repository.
2. Make sure `index.html` is in the repository root.
3. Open `index.html` locally to preview the website.

## GitHub Pages

You can publish the site with GitHub Pages:

1. Open the repository **Settings**.
2. Select **Pages**.
3. Under the deployment source, choose the `main` branch and root folder.
4. Save the settings.
5. GitHub will provide your public website address.

## Customization

### Contact email

The contact button currently uses:

`destinyacademy@example.com`

Replace it in `index.html` with the academy's real email address.

### Branding

The main brand color is controlled by:

```css
--brand:#635bff;
```

inside `style.css`.

### Courses

Course names and descriptions are located in the course grid in `index.html`, so they can easily be changed or expanded later.
